# Свадебное приглашение Давида и Алины

Готовый статический лендинг для GitHub Pages.

## Структура

- `index.html` — разметка всех секций;
- `styles.css` — адаптивный дизайн и анимации;
- `script.js` — конверт, музыка, календарь, тайминг, счётчик гостей и анкета;
- `assets/couple.jpg` — фотография пары;
- `assets/church.jpg` — фотография церкви;
- `assets/ararat.png` — фотография банкетного зала;
- SVG-файлы в `assets` — декоративные элементы.

## Музыка

Добавьте свой аудиофайл как:

`assets/music.mp3`

Браузеры запрещают автоматическое воспроизведение со звуком до взаимодействия пользователя, поэтому музыка запускается при открытии конверта.

## Отправка анкеты

GitHub Pages не обрабатывает формы на сервере. В `script.js` найдите:

```js
const FORM_ENDPOINT = '';
```

и вставьте endpoint Formspree или Google Apps Script. Пока endpoint пустой, ответ сохраняется только в `localStorage` браузера гостя.

## Публикация на GitHub Pages

1. Загрузите содержимое папки в корень репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/root`.
5. Сохраните настройки.
